# Arch User Repository packages

`zfetch-project-z` builds the tagged source with Rust 1.100 or newer. `zfetch-project-z-bin` installs the official static x86_64 or aarch64 release. Both provide `zfetch` and conflict with other providers. The names avoid taking over an existing, unrelated AUR package.

Each directory contains a PKGBUILD and the `.SRCINFO` generated by `makepkg --printsrcinfo`. Source and release archives use SHA-256 values; there are no skipped integrity checks or runtime dependencies. The binary package disables stripping so its executable stays byte-for-byte identical to the official release.

For an update, first complete the official tag release, download both architecture assets and SHA256SUMS, verify them, update the version and checksums, regenerate `.SRCINFO`, and run `makepkg` in a temporary directory. Validate the installed files before pushing the two AUR Git repositories.

The v0.1.0 source and binary packages were built locally. The source package used a directly verified rustup 1.100.0 toolchain with makepkg's pacman dependency check bypassed; no build, test or checksum step was skipped. namcap reports the intentional static non-PIE layout and lack of FULL RELRO. This small direct-syscall program does not provide a dynamic loader or a static-PIE relocation runtime. See [release evidence](../../docs/evidence/release-0.1.0.json) for exact binary hashes and validation records.
